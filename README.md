## 🖥️ Using the Application

The main window shows your device connection status and the current layout settings for your lower screen.

### Changing Layouts
You can select different themes or data views for your display. Open the "Layout Manager" tab to see available options. Select a layout and click "Apply" to push the change to your AYN Thor.

### Monitoring System Performance
The software tracks your device temperatures and battery levels. You can toggle these metrics on or off. If you want to see your battery status on the lower screen, check the box labeled "Show Battery Percentage."

### Troubleshooting Connection Issues
If the app fails to find your device, try these steps:

- Unplug the USB cable and plug it back in.
- Try a different USB port on your computer.
- Restart the Heimdall Assistant program.
- Restart your AYN Thor device.

## 💬 Frequently Asked Questions

**Does this software harm my AYN Thor?**
No. This tool only updates the display information for the lower screen. It does not modify system files or internal settings on your handheld device.

**Can I create my own layouts?**
Yes. You can import custom images or data widgets in the "Custom" tab. Create your layout files as standard image files and use the "Import" button to add them into the application library.

**Will this app run on older versions of Windows?**
No. This software requires Windows 10 or later to ensure the connection drivers operate correctly.

**Where do I report bugs?**
If you find an issue, select the "Help" menu inside the application and choose "Report Issue." This creates a log file that helps developers understand what went wrong on your system.
